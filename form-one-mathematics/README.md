# Education Access E-Learning Academy
## Form One Mathematics Curriculum

Module ID: EA-F1-MATH-2023

Version: 0.1.0

Status: Development

Authority: Tanzania Institute of Education (TIE)

Controlling Reference: Mathematics Syllabus for Ordinary Secondary Education Form I-IV (2023).

### Purpose
This package independently manages the Form One Mathematics curriculum, learning outcomes, weekly units, assessments, marking schemes and mastery evidence.

### Instructional Sequence
1. Discover
2. Learn
3. Practise
4. Knowledge Check
5. Apply
6. Voice
7. Journal
8. Friday Assessment
9. Evidence & Mastery

### Academic Governance
The TIE 2023 Mathematics syllabus takes precedence over Academy-developed materials.

All curriculum content must be traceable to the prescribed Form One syllabus.

### Development Principle
Curriculum content remains independent of the main Academy interface and is integrated through a controlled JavaScript module.
